# FishBase / SeaLifeBase staging data

`NameResolution.csv` maps every input name to a species; `Drafts/batch-NN.json` holds
the draft app records awaiting review, with `BuildReport.json` summarising them.
Generated by `Tools/FishBaseIntake` from pinned releases FishBase `v26.06` and
SeaLifeBase `v26.06` (see `Tools/FishBaseIntake/release_manifest.json`). Do not edit
these files by hand; re-run the tool instead.

Species names and SpecCodes here are derived from FishBase and SeaLifeBase, licensed
under CC BY-NC 4.0 (<https://creativecommons.org/licenses/by-nc/4.0/>). Dive ID
normalised and matched them to its own records.

- Froese, R. and D. Pauly. Editors. 2026. FishBase. World Wide Web electronic
  publication. www.fishbase.org, version (02/2026).
- Palomares, M.L.D. and D. Pauly. Editors. 2026. SeaLifeBase. World Wide Web
  electronic publication. www.sealifebase.org, version (06/2026).
